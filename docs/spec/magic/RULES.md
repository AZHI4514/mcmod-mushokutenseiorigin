# 魔法共同规则

只规定法术作用机制。单术覆盖需在[对应设计卡](INDEX.md)明确写出；原39术特例不套用扩展术的整发去重。学习不属于本合同。

## 单位与基础判定

1秒=20服务端tick；距离为格，速度为格/tick，重力为格/tick²；2生命点=1颗心。遵守原版护甲、抗火、无敌帧和PVP，除非本术明确覆盖。AOE表示同一作用区域伤害多个目标，不等于路径穿透。

伤害、MP、体积、速度不按等级统一倍增。标准附效时长=5r秒，恒速飞行时限=3r秒；特殊术独立计时优先。等级与计时模板不是学习资格，也不是角色等级。

## 原39术机制与特例

| 模式 | 规则 |
|---|---|
| 初速弹体 | 保留空气阻力，水0.03、火0.01、风0.01、冰0.02、土0.05重力；冰按冰系优先，不套水系重力。无固定距离/时间上限，按碰撞结束。 |
| 恒速弹体 | 无重力，速度不随空气阻力下降；达到等级飞行时限即消失，碰撞可提前结束；最远距离＝速度×20×时限。 |
| 即时生成/查询 | 没有飞行过程，弹体速度、重力、弹体持续时间均不适用；保留选点距离和遮挡判定。 |

恒速弹体时限统一见[施法合同](../casting/CONTRACT.md)。

- 飞行弹体触碰实体、方块、流体或虚空结束；所有恒速法术均为穿透法术，碰生物结算伤害后继续，并穿过水、流水及具有WATERLOGGED属性的不完整方块（含当前干燥状态）；不支持含水的实体方块与熔岩仍阻挡。火断、冰霜刃保留完整截面遮挡特例。
- 虚空为世界底部虚空区域，不等于暂未加载区块；前方区块未加载时挂起，不强制加载；恢复后继续，弹体状态随实体保存，不额外增加超时。
- 临时方块、屏障、领域及状态时长均写在附效字段，与弹体持续时间分开。即时生成法术只右手发光，不发射可见光线，也不存在不可见飞行判定。

| 效果 | 概率/时间 |
|---|---|
| 水系 | 成功伤害后通常60%湿身，时长按[施法合同](../casting/CONTRACT.md)。水盾按接触判定；水蒸100%湿身100秒；水瀑100%湿身10秒。 |
| 冰系 | 成功伤害后80%魔法冻结，时长按[施法合同](../casting/CONTRACT.md)。要求目标可冻结且无温暖；维持原版冻结计数与冻伤/抵抗。 |
| 火系 | 成功伤害后通常80%点燃，时长按[施法合同](../casting/CONTRACT.md)。排除火免/抗火；原版TNT起火另算。 |
| 湿身 | 本身无额外增伤/减速；冰结领域可消耗湿身造冰。 |
| 温暖 | 清冻结/冻伤并防冻；灼热手10秒，地热接触中刷新5秒。 |
| 重复附效 | 通常刷新不累加；护盾/领域的付费续期增加其存在时间，按各术规定。 |

完成咏唱后预扣10MP并注魔，松V或MP耗尽发射；中断取消并退还预扣MP。只显示本次已投入MP数字，无进度条。发射后冷却0.5秒。

```text
n＝注魔tick数，t＝n/20秒
额外累计 E(n)＝floor((40n＋n²)/80)＝floor(10t＋5t²)
每tick注入＝E(n)−E(n−1)，受剩余MP限制
连续近似注魔速度＝10＋10t MP/秒
总支付 P＝10＋实际额外注入
伤害 D＝10＋floor(max(0,P−10)/10)
```

额外不足10MP部分仍消耗，但不形成增伤。注魔只提高伤害，不改变恒速3格/tick、中级6秒时限或穿透；理论飞行最远360格。满魔100约68tick/3.4秒耗尽，总付100MP、伤害19。单击按经过tick扣费，不保证总付恰好10MP。

- 水盾与地热原地才可续期；燃烧领域、魔力障壁跟随角色；物理屏障原地续期。松V或中断维护后重放按新实例处理，同人同术领域仅一个。
- 水瀑、火焰放射采用每tick分摊整点预付的持续扣费；停止后0.5秒冷却。源头永久不代表停止后仍无限刷新湿身。
- 土落弹从选点上方6格持续下坠，生物命中不停止，每目标8伤害一次；碰方块或流体停止，空间足够才造完整永久石块；虚空消失。
- 即时查询五术保留12格选点距离：冰柱/冰枪选首个生物或方块；水瀑定期选点放水；风缚选生物；土枪仅生物与自身脚下分支。土落弹另按12格选点后生成下坠巨岩。未命中不把效果延迟成飞行弹体。
- 常规改地形遵守权限、边界与出生点保护，仅在已加载可处理位置操作；临时冰按记录清理且无正常掉落，滴水石按记录状态清理、其他原版交互保留。原版TNT采用其自身破坏规则。
- 火柱只在初次命中位置放地形火，不沿目标移动路径放火；自然蔓延/熄灭仍属原版规则。

## 扩展术适用的额外约束

以下“新增”只指原63项扩展术范围，不追溯改写原39术。

- 新增普通法术的伤害、MP、范围逐术给定，不套统一伤害倍率。
- 即时选点：施法结束重新检查射程与遮挡；除气象、召唤阵、传送网络外，默认需要看得到中心点。
- 新增恒速弹体：全部穿透生物，每发每目标最多一次直接伤害；可过水及具有WATERLOGGED属性的不完整方块，普通实墙与熔岩阻挡。表内“命中爆发”若沿途连续触发，对同目标仍整发最多一次直接伤害，不因重叠AOE刷伤害。
- 现有「爆炸」多目标触发TNT的特殊规则保留，不套用新增法术的去重方案。
- 下列地面阵、领域、落雷、即时净化没有飞行弹体，不凭名称获得穿墙/穿水能力。恒速时限只作用于明确标“恒速”的术。
- 新增伤害领域释放时立即结算第一次；标“每秒”的在0、1、2……秒结算，到持续时间终点不再补一次。每0.5秒同理；每目标遵守原版受伤限制。
- 默认领域/爆发只影响可见目标：从中心/最近可见表面至目标检查实墙遮挡。气象雨水只影响露天目标；落雷须有垂直天空路径。声波、标记与特殊透视的例外在本术另写。
- 临时领域默认包含施术者且可误伤友方；纯治疗、净化己方、明确“不伤自身”的术例外。队友识别使用原版队伍，不擅自把所有玩家当友军；受PVP配置约束。新法术可在施法界面预览作用体积。

### 2.3 附效、控制、地形与首领

- 新增水/冰/火的常规附效沿用60%湿身、80%冻结、80%点燃，标准时间=5r秒。冻结指既有魔法冻结与冻伤逻辑，**不是所有冰术都定身15–35秒**。明确写100%、特殊时长和硬控的术覆盖通用概率。
- 新增硬控对玩家单次最多2秒，对普通生物按单术，对龙/凋灵/监守者免疫；同目标硬控结束后3秒内再次硬控时长减半、至少0.25秒。软减速不计硬控；现有风缚规则不改。
- 电击“穿透斗气”设计为穿透未来斗气减伤，不穿原版护甲与保护附魔，不无条件清除吸收生命。
- 高阶天气和区域效果是局部领域，不改变整个维度天气、不生成无限水源、不强制加载区块；同施术者同术只保留一份。同类减速/天气不叠加，同系每目标采用最高伤害频率，避免重叠领域按数量倍增；异系仍走原版无敌帧。
- 高阶地形法术可真实改地形；**新术**默认关闭永久破坏，临时地形开启。可通过服务端配置开启永久模式；不改变现有39术的TNT、永久石头/泥土等已确认行为。
- 临时地形只填空气/允许替换的无实体植物与本次指定流体，不覆盖容器、方块实体、基岩和受保护位置；无掉落、不可推入容器；旧方块/流体用持久化记录恢复，清理时若已被其他玩家合法改动则不覆盖其新状态。永久模式须额外遵守领地/出生点/方块修改权限。每次新术临时地形最多8192格、每tick最多400格，神级按队列铺开；地形数值上限不缩小实体伤害/视觉范围。
- 所有范围明确几何体。大范围视觉不靠每tick生成海量实体，而用体积模型、分区像素粒子和距离LOD；高等级增加层次、天气、冲击波与余波，不恢复持续满屏的咏唱粒子。

## 单术时长例外

水蒸100%湿身100秒；灼热手温暖10秒、地热接触刷新5秒；风缚控制5秒、强风缓降5秒及原版地形火不套标准附效时长。伤害、治疗、持续扣费、注魔增伤、速度、范围、击退、容量与临时方块寿命不随术阶自动增长。
