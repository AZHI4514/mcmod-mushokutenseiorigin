# 冰结领域 · `icicle_field`

规则归属：本术效果与数值。设计目标见[魔法意图](../../../intent/MAGIC.md)；共同规则见[通用魔法规则](../RULES.md)。本卡不拥有教材、学习前置、按键或代码路径。

## 玩法规则

| 字段 | 设定 |
|---|---|
| 等级 | 中级 |
| 按键与释放逻辑 | 完成咏唱后即时选点；方向查询（不可见）落空取12格端点 |
| MP | 14/次 |
| 伤害 / 治疗 | 5点 |
| AOE伤害 | 是；落点半径6格球形，可见生物各5伤害。 |
| 运动 / 射速 / 重力 | 不适用（无飞行弹体）。 |
| 作用距离 / 生成范围 | 准星最远12格落点；半径6格球形范围 |
| 弹体持续时间 | 不适用。 |
| 附加 / 附近效果及其持续时间 | 成功伤害后80%冻结10秒；命中前已湿身者消耗湿身，中心3×3×3填临时冰，中心不刻意留空，冰持续6秒。 |
| 穿透与命中 | 生物穿透：不适用；连续攻击：不适用；生成方块窒息：按原版对应方块规则。 |
| 碰撞与触发规则 | 范围攻击；视线判断；先收集再造冰 |
| 破坏方块 / 生成方块或物品 | 湿身目标中心生成3×3×3临时冰，只填空气，正常到期无掉落。 |

## 验收合同

- 正常：满足资格与本术目标条件，按上表支付MP并产生规定效果，不追加未设计的伤害或地形。
- 边界：逐项验证上表距离/体积/时间边界；不适用字段明确N/A，不凭名称推断范围。
- 失败与中断：遵守施法合同；无效果拒绝与不可逆部分异常分别处理，不能统一假定退款。
- 兼容：保留本ID、旧存档与资源标识；具体测试位置由实现索引导航。

这些是要满足的条件，不是测试执行结果；新增改动仍需在任务卡写出具体Given/When/Then样例。
