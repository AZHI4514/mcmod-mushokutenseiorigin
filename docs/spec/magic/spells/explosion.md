# 爆炸 · `explosion`

规则归属：本术效果与数值。设计目标见[魔法意图](../../../intent/MAGIC.md)；共同规则见[通用魔法规则](../RULES.md)。本卡不拥有教材、学习前置、按键或代码路径。

## 玩法规则

| 字段 | 设定 |
|---|---|
| 等级 | 中级 |
| 按键与释放逻辑 | 完成咏唱后盲发/按住重复咏唱；无命中则消失、不爆炸 |
| MP | 16/次 |
| 伤害 / 治疗 | 原版强度4 TNT爆炸动态计算；定义中10不参与当前爆炸伤害计算 |
| AOE伤害 | 是；原版强度4 TNT爆炸，实体检测距离约8格，按距离/遮挡衰减，不是该范围同伤。 |
| 运动 / 射速 / 重力 | 恒速2格/tick；无重力，不受阻力改变速度。 |
| 作用距离 / 生成范围 | 无障碍理论最远240格（速度×等级飞行时限）；伤害形状见AOE字段。 |
| 弹体持续时间 | 6秒 / 120tick；碰撞可提前结束。 |
| 附加 / 附近效果及其持续时间 | 原版TNT强度4动态伤害/击退与起火；火焰按原版存续及蔓延，不套用统一80%点燃规则。 |
| 穿透与命中 | 生物穿透：是；连续攻击：每个经过生物每发一次；生成方块窒息：不适用。 |
| 碰撞与触发规则 | 按通用碰撞规则结束；穿透法术对每个生物每发最多伤害一次。命中生物/方块触发原版TNT爆炸；流体仅终止弹体。 |
| 破坏方块 / 生成方块或物品 | 原版TNT强度4破坏、掉落和起火。 |

恒速穿透规则：经过生物时结算原有伤害/范围效果后继续飞行，每发记录已触发生物；碰不支持含水的阻挡方块或熔岩仍结束。水、流水、所有具有WATERLOGGED属性的不完整方块（干燥/含水均可）不阻挡；不破坏被穿过的方块。爆炸保留原爆炸结算，经过不同目标可再次引爆，重叠爆炸仍遵守原版伤害规则。

## 验收合同

- 正常：满足资格与本术目标条件，按上表支付MP并产生规定效果，不追加未设计的伤害或地形。
- 边界：逐项验证上表距离/体积/时间边界；不适用字段明确N/A，不凭名称推断范围。
- 失败与中断：遵守施法合同；无效果拒绝与不可逆部分异常分别处理，不能统一假定退款。
- 兼容：保留本ID、旧存档与资源标识；具体测试位置由实现索引导航。

这些是要满足的条件，不是测试执行结果；新增改动仍需在任务卡写出具体Given/When/Then样例。
