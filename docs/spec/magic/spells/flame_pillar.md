# 火柱 · `flame_pillar`

规则归属：本术效果与数值。设计目标见[魔法意图](../../../intent/MAGIC.md)；共同规则见[通用魔法规则](../RULES.md)。本卡不拥有教材、学习前置、按键或代码路径。

## 玩法规则

| 字段 | 设定 |
|---|---|
| 等级 | 中级 |
| 按键与释放逻辑 | 完成咏唱时须命中12格内生物或方块；没有有效位置失败 |
| MP | 12/次 |
| 伤害 / 治疗 | 每次3点，首次/约1秒/约2秒共3次，直接伤害理论合计9；原版燃烧/地形火另算 |
| AOE伤害 | 否；无范围伤害。 |
| 运动 / 射速 / 重力 | 不适用（无飞行弹体）。 |
| 作用距离 / 生成范围 | 生物或任意方块表面，准星最远12格 |
| 弹体持续时间 | 不适用。 |
| 附加 / 附近效果及其持续时间 | 伤害任务3秒，首次及约1秒、2秒各3火伤；首次点燃3秒，成功火伤另有80%刷新燃烧为10秒。地形火只首次命中处生成，后续伤害不沿移动路径放火，原版自然蔓延保留。 |
| 穿透与命中 | 生物穿透：不适用；连续攻击：不适用；生成方块窒息：不适用。 |
| 碰撞与触发规则 | 对选中生物，不是范围火柱；不穿墙 |
| 破坏方块 / 生成方块或物品 | 首次生物命中位置脚下，或目标方块旁/上方可存续空位生成原版火。 |
