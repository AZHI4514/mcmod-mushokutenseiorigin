## 玩法规则

| 字段 | 规则 |
|---|---|
| 等级/计时模板 | 上 |
| MP | 38 |
| 游戏效果与准确范围 | 直径1.5、长3钻风，恒速3格/tick，经过每目标16伤害，附朝飞行方向1.0速度冲量 |
| 形态/时长/地形 | 9秒、理论540格；实墙挡，不自动破墙；永久模式可破路径内最多64个石制工具可采方块 |

## 补充机制约束

38MP、16伤害、恒速3格/tick、9秒；每目标整发一次伤害，成功伤害后向前1.0冲量，首领免冲量。永久模式按扫掠顺序处理路径，整发最多64格，不可采或受保护方块仍阻挡。
