# 冰柱 · `ice_pillar`

规则归属：本术效果与数值。设计目标见[魔法意图](../../../intent/MAGIC.md)；共同规则见[通用魔法规则](../RULES.md)。本卡不拥有教材、学习前置、按键或代码路径。

## 玩法规则

| 字段 | 设定 |
|---|---|
| 等级 | 中级 |
| 按键与释放逻辑 | 完成咏唱后即时触发；按住重复咏唱，不发光线、不保留不可见飞行过程。 |
| MP | 8/次 |
| 伤害 / 治疗 | 4点 |
| AOE伤害 | 是；生成位置1×3×1柱体区域，柱内目标各4伤害一次，无圆形半径。 |
| 运动 / 射速 / 重力 | 不适用（无飞行弹体）。 |
| 作用距离 / 生成范围 | 12格内首个生物/方块，命中位置生成1×3×1冰柱。 |
| 弹体持续时间 | 不适用。 |
| 附加 / 附近效果及其持续时间 | 生成1×3×1临时冰柱10秒，弹起柱内生物并造成4伤害；80%冻结10秒，每次生成对同一目标伤害一次。 |
| 穿透与命中 | 生物穿透：不适用；连续攻击：不适用；生成方块窒息：按原版对应方块规则。 |
| 碰撞与触发规则 | 即时选点/目标判定，遵守12格距离与遮挡；无有效目标时不生成，不以飞行触碰触发。 |
| 破坏方块 / 生成方块或物品 | 生成1×3×1临时冰柱，只填空气，正常到期无掉落。 |
