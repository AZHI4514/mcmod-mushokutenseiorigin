# 土落弹 · `earth_pillar`

规则归属：本术效果与数值。设计目标见[魔法意图](../../../intent/MAGIC.md)；共同规则见[通用魔法规则](../RULES.md)。本卡不拥有教材、学习前置、按键或代码路径。

## 玩法规则

| 字段 | 设定 |
|---|---|
| 等级 | 中级 |
| 按键与释放逻辑 | 完成咏唱后选点生成下坠巨岩；按住重复咏唱。 |
| MP | 14/次 |
| 伤害 / 治疗 | 8点 |
| AOE伤害 | 否；下坠路径扫掠伤害，穿过多个生物不计为中心爆炸AOE。 |
| 运动 / 射速 / 重力 | 垂直下坠0.5格/tick，不沿准星方向飞行，无额外重力加速。 |
| 作用距离 / 生成范围 | 最远12格选点，在选点上方6格生成完整3×3×3巨岩。 |
| 弹体持续时间 | 无固定时间上限；触及方块、流体或虚空后停止下坠；碰到生物不停止。 |
| 附加 / 附近效果及其持续时间 | 经过生物造成8点伤害，每目标每次施法一次；不额外附加状态。 |
| 穿透与命中 | 生物穿透：是；连续攻击：每个经过生物每次施法一次；生成方块窒息：按原版石头规则。 |
| 碰撞与触发规则 | 完整巨岩持续下坠；首次触及非空气方块或流体停止；进入世界底部虚空消失；未加载区块挂起。 |
| 破坏方块 / 生成方块或物品 | 不破坏方块；方块或流体接触时，若完整空间与权限允许，生成3×3×3永久石头；不覆盖原有方块，空间不足则不造石并移除巨岩。 |

## 验收合同

- 正常：满足资格与本术目标条件，按上表支付MP并产生规定效果，不追加未设计的伤害或地形。
- 边界：逐项验证上表距离/体积/时间边界；不适用字段明确N/A，不凭名称推断范围。
- 失败与中断：遵守施法合同；无效果拒绝与不可逆部分异常分别处理，不能统一假定退款。
- 兼容：保留本ID、旧存档与资源标识；具体测试位置由实现索引导航。

这些是要满足的条件，不是测试执行结果；新增改动仍需在任务卡写出具体Given/When/Then样例。
