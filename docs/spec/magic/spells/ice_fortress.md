# 冰砦 · `ice_fortress`

规则归属：本术效果与数值。设计目标见[魔法意图](../../../intent/MAGIC.md)；共同规则见[通用魔法规则](../RULES.md)。本卡不拥有教材、学习前置、按键或代码路径。

## 玩法规则

| 字段 | 设定 |
|---|---|
| 等级 | 中级 |
| 按键与释放逻辑 | 完成咏唱后即时生成；空间或权限不足失败；不是向12格准星落点造墙 |
| MP | 14/次 |
| 伤害 / 治疗 | 0点 |
| AOE伤害 | 否；无范围伤害。 |
| 运动 / 射速 / 重力 | 不适用（无飞行弹体）。 |
| 作用距离 / 生成范围 | 与玩家脚同Y、准星水平方向前方2格；宽5×高3×厚1，墙体按水平主轴放置 |
| 弹体持续时间 | 不适用。 |
| 附加 / 附近效果及其持续时间 | 临时冰墙10秒，可站立并遮挡。 |
| 穿透与命中 | 生物穿透：不适用；连续攻击：不适用；生成方块窒息：按原版对应方块规则。 |
| 碰撞与触发规则 | 真实临时方块阻挡；不穿透地形 |
| 破坏方块 / 生成方块或物品 | 生成宽5×高3×厚1临时冰墙，只填空气，正常到期无掉落。 |
