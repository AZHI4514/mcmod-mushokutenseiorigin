## 输入与界面

3. **G**：魔法知识。查看已学魔法、轮盘列表、魔力消耗、冷却、属性和伤害。移除只卸载，不遗忘。
4. **按住 R**：在视角中央打开小圆盘，左右键点击扇区选择，松开 R 关闭。可继续移动、跳跃、潜行；鼠标不与世界交互，其他 GUI 中不能打开。
5. **按住 V**：连发，松开停止。空手、手持普通物品均可，不依赖法杖。按键均可在原版控制设置的「无职转生：魔法」中重绑。
6. HUD 蓝色条和数字位于九格栏右侧、底边齐平，标准宽度与一行原版血量相同（81 GUI 像素）；已选法术名称使用原版药水背景显示在右上角；无已学法术时不显示法术名称。普通玩家 GUI 无上限修改入口。

任何 GUI、失焦、死亡、旁观、吃东西/拉弓等物品使用都会阻止施法；结束后必须松开并重新按 V。原版物品使用动作优先，不取消原版行为；已经发射的弹体继续存在。

普通法术只在成功释放后付主术费用；持续法术完成准备再持续付费，停止后恢复；注魔先准备再注入，发射后恢复。部分世界异常不假设能撤销已经发生的伤害；具体事务边界见实现说明。

`/mtcombo ice_lance_blizzard`只顺序调用冰枪和吹雪，各自正常咏唱、费用和恢复，不增加独立学习ID。两术必须已学且已装槽；`/mtcombo cancel`或松键/打断取消组合。

Shift+V在施法前切换复合障壁、大气掌握、重力和核爆预设；`/mtnuclear <0..3000>`选额外MP，基础3000不变。神级七层HUD表示准备进度，不是自由阵面编辑器。

## 验收条件

准备取消不扣主术MP/CD；有效输入在冷却后开始下一轮；原版物品动作优先；持续/注魔不得重复创建准备会话；多人下由服务端裁决成功。执行结果只写STATUS和日志。
