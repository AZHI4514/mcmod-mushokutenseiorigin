# 魔法书与学习合同

拥有：教材、学习资格、课程、学习谱、已学知识。法术只提供ID与效果；本系统引用ID，不在法术设计中塞入书的外观或课程逻辑。

## 教材与学习

分类教材按当前已注册法术的实际类别与等级生成课程，覆盖已实现的初—神级法术；冰归水，解毒独立于治愈，混合、神击、召唤、特殊按实际目录分类。不得把旧14/16本的数量作为当前固定白名单。塞妮丝书从`SpellDefinition.ALL`生成全部102项，入门书保留原39项；组合不另建学习ID，暂缓未注册术不收录。法术简介参考[原作设定](../../reference/LORE.md)，游戏数值以正式游戏规格及定义核对，分类教材显示非空前置。

学习由服务端校验实际持书、课程和前置；分类教材生成随机A–Z银河字母谱，仅显示原版ascii_sga字形，不显示对应英文字母。玩家用字母键逐个尝试，按错不失败、不推进、不清空已点亮进度；无倒计时、漏拍或精度门槛，全部按顺序点亮即学会。初级4–6枚、中级6–8枚，上级8–10枚、圣级10–12枚；王级3段各8–10枚、帝级4段各10–12枚、神级7段各10–12枚。王/帝/神级保存已完成段，退出时当前未完成段重来。退出界面、死亡和换书取消会话；塞妮丝与入门书仍按各自目录直接学习。

前置关系的唯一维护位置是[CURRICULUM](CURRICULUM.md)。原39术为入门书固定收录范围；塞妮丝书收录全部注册ID。分类教材按类别/等级查询收录，禁止固定成旧14本数量。

## 操作与资产

创造模式取得塞妮丝的魔法书，或`/give @s mushokutenseiorigin:zenith_greyrat_magic_book`。右键翻到法术页，点击学习。槽满仍可学习，知识永久保留；轮盘只是已学法术的装备栏。

书保留原版书形状，32×32透明图标；分类教材棕色皮革、塞妮丝书浅棕封面、米色纸页，分类符号清晰逐像素描绘，避免斜向缩放混色。运行时只用相对资源ID；外部绘画工程是工作素材而不是运行依赖。

学习输入只用按键事件，不接受系统长按重复。服务端确认完成索引，检查实际持书、课程和前置；客户端不可伪造学习成功。

## 验收条件

分类教材拒绝不满足前置者；两本直学书绕过学习谱但不绕过未来施法费用；错误字母不推进、不清空；高阶仅保存完成段；退出/死亡/换书取消会话；重登保留已学知识。
