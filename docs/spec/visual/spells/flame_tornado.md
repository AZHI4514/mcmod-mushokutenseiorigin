## 最终方案需要定义的字段

| 设计项 | 需要形成的设计结论 |
|---|---|
| 轮廓与尺度 | 主体、负空间、正侧后辨识度；外观边缘与判定边缘的关系 |
| 凝聚/释放 | 从哪里出现、层次怎样建立、何时交接到真实释放事件 |
| 运动/维持 | 按玩法类型明确适用阶段、跟随对象与方向；非弹体不强加飞行 |
| 命中/解除 | 命中层次、扩散、碎屑/烟雾及自然消退；取消、到期与失败反馈 |
| 像素材质 | 色板、像素尺度、透明层、亮暗结构；禁止平滑材质冒充像素风 |
| 粒子/音效 | 随机体积分布、疏密节奏、层级、音色、近景遮挡与距离降级 |
| 技术预算 | 评审后确定模型/帧/透明层/粒子预算；不继承占位实现的数量为目标 |

上表是需要填实的设计字段，**不是已经批准的最终方案**。逐术设计任务应把它们替换为具体分镜、比例、参考帧和可验收描述；没有证据不编造参数。制作流程见[视觉工作流](../../../development/VISUAL_WORKFLOW.md)。
