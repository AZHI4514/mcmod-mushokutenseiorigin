# 公共咏唱表现

本文件拥有所有法术共享的准备表现，不决定咏唱需要多久、何时付费或何时打断；这些从[施法合同](../casting/CONTRACT.md)读取。独有的凝聚主体由单术视觉卡定义。

- 银河文字每4tick输出一个银河字母，从人物左眼斜向上漂浮、渐隐；不改回头顶文字。文字表现不能控制准备成功。
- 手前粒子随机分散在三维空间，疏密按连续周期脉动，高峰与低谷明显；不持续满屏，不只沿一条线发射。等级越高层次更丰富，但保留近眼可读性。
- 双臂保留物理右臂前伸、左臂靠近右前臂的姿态中心，并有轻微连续动作，不能固定不动；原版持物操作优先。具体动画曲线与幅度由重做方案确定，不把旧4.64度等实现值冻结成目标。
- 成功手部提示与对应法术元素一致；持续效果按有效状态显示，准备取消/施法失败不伪装成成功释放。

重做时需定义第一/第三人称、不同皮肤、持物遮挡、动作过渡和文字/粒子预算；修改共享层先测试至少弹体、持续、领域、注魔四类，避免逐术复制公共动作代码。执行状态只在STATUS。
