# 世界交互合同

拥有法阵、结晶、核心、传送、通信及召唤生命周期；单术伤害仍归魔法卡。下述操作界面是合同，实际实现局限在impl说明，验收执行在STATUS。

- 神级普通阵采用7×7有效阵面，中心空高3；8枚魔力结晶作阵材。结晶配方：紫水晶碎片×4+青金石×4合成1枚未充能结晶，右键注入25MP成为阵材；结晶能量用于构阵，表中MP另行支付，避免混淆。
- 传送阵5×5，需中心符石及4枚结晶；城塞核心储能上限6000MP，真实注入/扣除；魔神五核心各需4枚阵材。特殊多层阵以7×7平面+界面7层术式表示，不要求堆七层实体建筑。
- 神级阵材成功释放消耗；中断不消耗阵材、不扣主术MP，已完成供能转入核心的MP不自动退款。阵损坏、离开阵心3格、GUI/物品动作打断按既有规则处理。

### 阵面、核心与供能

- 普通神级7×7阵：中心磁石，四角(±2,±2)及四轴端(±3,0)/(0,±3)紫水晶块，其余磨制深板岩，中心上3格空气；成功释放消耗8枚充能结晶。中断不消耗主术费/阵材。
- 传送5×5阵：中心磁石、四角紫水晶块、其余磨制深板岩，中心上3格空气；中心符石以磁石承载，没有重复注册同功能方块。本人站阵心执行`/mtteleport register <name>`，消耗4枚充能结晶，每人最多64阵。
- 看向6格内磁石执行`/mtcore create`，消耗4枚充能结晶生成可破坏核心；`/mtcore charge <mp>`真实扣自身MP并充入最近6格内本人核心，上限6000；`/mtcore status`查询。外形为悬浮紫晶、碎晶与交错术环；禁止右键换装备。
- 城塞消耗最近有效核心储能，每秒10、回复容量8；断供5秒消散。魔神封印要求5核心位于目标周围半径12正五边形（各误差2格），90秒全程锁定同一目标和核心；各扣400储能。目标须≤20%生命且在`sealable`实体标签内，默认不封玩家。任核心失效解除。

### 传送与通信

- `/mtteleport list / destination <name> / preview / forget <name>`管理本人登记阵；`invite <player>`发60秒邀请，对方`accept <caster>`或`decline`。施法者加半径2内最多3名接受的玩家/本人宠物；不带陌生实体、散落物、骑乘者或有乘客的实体。
- 30秒咏唱锁定源阵、目的阵、总费和旅客UUID；阵损坏、离开源阵2格、名单或费用改变取消。目的地只用已加载区块，预检实体体积、世界边界、无液体、落脚与火/细雪等危险；多实体预留互不重叠落点。逐个传送异常时逆序回滚已移动者，失败不收主术费；跨维实体重建和第三方传送拦截仍须联机实测，不能声称已证明任意插件下严格原子性。
- 同维度≤2048格，费用160+2×ceil(距离/16)；跨维额外400，白名单默认只有主世界，可在`config/mushokutenseiorigin-magic.json`添加`"teleportDimensionWhitelist": ["minecraft:overworld", "minecraft:the_nether"]`。不强载，不自动放宽服务器规则。
- `/mtcommunication bind <player>`双方分别绑定；`draft <player> <message>`准备最多120码点的60秒草稿，选择通信术正常施法；`mute / unmute / unbind <player>`管理接收。发送复查在线、双向绑定、静音、聊天可见性，沿用签名聊天和过滤，不接外部网络。

### 召唤与领域生命周期

- `/mtsummon follow / stay / attack / protect / dismiss`控制已有召唤；保护仅适用精灵。owner/slot/expiry持久保存，卸载不复制，到期清理；禁止掉落、交易、拾取和装备交互，不能瞬移攻击。
- 两只死灵共同维护2MP/秒；每次另付启动费用，只消费普通非玩家生物尸体记录。同一记录仅消费一次，不可掉落、交易，到期清理。
- 临时地形与灯灵光源在真实方块变更后放弃恢复权；每维度400次修改/tick，装配队列每tick最多12格，不强载区块。
- 领域保存起止时间与已结算脉冲；卸载错过的周期不逐次补发，重载不重播一次性冲击。
