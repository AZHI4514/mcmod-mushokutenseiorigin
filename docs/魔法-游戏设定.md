# 魔法·游戏设定

适用：Minecraft 26.1 / Fabric；更新：2026-11-07。共39术（初级15、中级24）。已同步本轮代码实现；编译及离线行为测试通过，游戏内表现待实测。

## 1. 通用规则

- 1秒＝20服务端tick，速度单位为格/tick，重力单位为格/tick²；1伤害＝半颗心。保留原版护甲、抗火、无敌帧和PVP规则。
- V施法，可重绑；默认完整咏唱，按住完成后释放；后冷却结束后可继续咏唱。水瀑/火焰放射先咏唱再持续扣费；岩炮弹先咏唱再注魔，松V释放。空手可施法，不要求法杖。
- G打开知识；按住R开轮盘，松开关闭，左右键选法术。最多10槽，轮盘允许移动但屏蔽世界左右键交互；其他GUI中不能打开。
- GUI/失焦/原版物品使用/死亡等打断施法，恢复后需松V重按。MP不足或CD未结束不新增施法；生成失败退款；治疗满血、解毒无可清状态不扣MP/CD。
- 默认魔力上限100，可配置/管理；降低上限截断，提高不回满。在线存活24000tick、成功参与睡眠推进早晨、死亡重生回满；知识、轮盘、选择与魔力持久保存。
- 初级/中级各设火、水、风、土、治愈、解毒、结界7类教材，共14本，冰归水；按分类与等级收录，均可自由翻页。学习自动加入有空位的轮盘，移除轮盘不遗忘。
- 成功施法才右手发光：普通法术每次成功释放闪光，按住V按成功节奏重复；持续施法有效期间保持光；岩炮弹成功发射时闪光。原版右手动作优先。
- 颜色：水/冰水蓝、火红、风白、土棕、治愈绿、解毒绿；魔力障壁水蓝、物理屏障结界紫。
- AOE仅指同一中心/区域内多个目标受到伤害；沿路径穿透多个生物不算AOE。球形用半径，柱体、环带、锥形、方盒明确标形状，不把边长写成半径。

## 2. 术阶数值统一约束

本节是后续新增魔法的统一依据；除明确登记的特例外，各法术不得自行覆盖。术阶属于法术，不是玩家等级或注入魔力量；注魔增伤不改变术阶、所属教材或以下时长。

| 上级 | 3 | 12 / 1 | 5 / 1 | 0.4 / 2 | 9 | 15 | 随机8–10，预留 |

### 2.2 适用范围与公式

- 服务端以tick计时：1秒＝20tick。一次普通施法周期＝咏唱＋后冷却；按住V须等待本轮结束才能开始下一轮咏唱。咏唱中断不扣MP、不进后冷却。
- 持续法术先完成咏唱，再按本术MP/秒扣费，停止后开始后冷却；注魔法术先完成咏唱，再进入注魔，发射后开始后冷却。持续和注魔时长不包含在表中的咏唱时长内。
- 恒速弹体时限＝3r秒＝60r tick；恒速弹体无重力，最远理论距离＝本术速度×60r。该时限不套用于初速弹体、下坠物、即时生成、屏障或领域；它们按各自动作/碰撞/持续规则结束。
- 标准附效时长＝5r秒＝100r tick，适用于按术阶计时的湿身、魔法冻结、点燃等状态；通常重复刷新，不累加。它不等于弹体寿命或护盾、领域、临时方块的存在时间。
- 初级至圣级学习谱数量＝2r＋2＋随机整数[0,2]，只在创建学习会话时抽取。按错不失败、无限时，顺序点亮全部字母才通过；王级以上不得据此自动扩展。

### 2.3 不随术阶自动增长的数值

- 伤害、治疗量、MP、持续扣费、注魔速率与增伤、速度、选点距离、AOE范围、击退、护盾容量、领域/临时方块时长，均按单个法术明细定义；没有统一等级倍率，不得自行套用翻倍或线性增伤。
- 默认水系附效概率60%，冰系80%，火系80%，不随术阶提升；有效目标、抗性和触发条件仍按附效规则。重力按元素而非术阶规定。
- 水蒸固定100%湿身100秒、灼热手温暖10秒、地热温暖刷新5秒、风缚控制5秒、强风漂浮1秒及原版地形火等明确特例，按对应法术明细执行，不被标准附效公式覆盖。

### 2.4 新法术接入要求

- 为新法术明确术阶，复用统一咏唱参数、恒速寿命和标准附效接口；将学习前置及教材分类显式登记。不得依据伤害大小、执行器类型或注入魔力推测术阶。
- 若需要覆盖本节的通用规则，必须先在本节或该法术明细标明覆盖字段、数值与适用条件，再改代码；未定的高阶学习/解锁规则保留接口，不默认放行。
- 复用 `CastingProfile`、`MagicRules.flightTicks/statusTicks`、`ChantScore.noteCount`；后续扩展高阶时须同步扩展术阶识别，验证边界值，避免现有实现将新高阶法术归成初级/中级。

## 3. 弹体运动与时限

| 模式 | 规则 |
|---|---|
| 初速弹体 | 保留空气阻力，水0.03、火0.01、风0.01、冰0.02、土0.05重力；冰按冰系优先，不套水系重力。无固定距离/时间上限，按碰撞结束。 |
| 恒速弹体 | 无重力，速度不随空气阻力下降；达到等级飞行时限即消失，碰撞可提前结束；最远距离＝速度×20×时限。 |
| 即时生成/查询 | 没有飞行过程，弹体速度、重力、弹体持续时间均不适用；保留选点距离和遮挡判定。 |

恒速弹体时限统一见第2节。

- 飞行弹体触碰实体、方块、流体或虚空结束；生物穿透法术例外，碰生物伤害后继续。火断、冰霜刃保留完整截面遮挡特例。
- 虚空为世界底部虚空区域，不等于暂未加载区块；前方区块未加载时挂起，不强制加载；恢复后继续，弹体状态随实体保存，不额外增加超时。
- 临时方块、屏障、领域及状态时长均写在附效字段，与弹体持续时间分开。即时生成法术只右手发光，不发射可见光线，也不存在不可见飞行判定。

## 4. 附效规则

| 效果 | 概率/时间 |
|---|---|
| 水系 | 成功伤害后通常60%湿身，时长按第2节。水盾按接触判定；水蒸100%湿身100秒；水瀑100%湿身10秒。 |
| 冰系 | 成功伤害后80%魔法冻结，时长按第2节。要求目标可冻结且无温暖；维持原版冻结计数与冻伤/抵抗。 |
| 火系 | 成功伤害后通常80%点燃，时长按第2节。排除火免/抗火；原版TNT起火另算。 |
| 湿身 | 本身无额外增伤/减速；冰结领域可消耗湿身造冰。 |
| 温暖 | 清冻结/冻伤并防冻；灼热手10秒，地热接触中刷新5秒。 |
| 重复附效 | 通常刷新不累加；护盾/领域的付费续期增加其存在时间，按各术规定。 |

## 6. 岩炮弹注魔

完成咏唱后预扣10MP并注魔，松V或MP耗尽发射；中断取消并退还预扣MP。只显示本次已投入MP数字，无进度条。发射后冷却0.5秒。

```text
n＝注魔tick数，t＝n/20秒
额外累计 E(n)＝floor((40n＋n²)/80)＝floor(10t＋5t²)
每tick注入＝E(n)−E(n−1)，受剩余MP限制
连续近似注魔速度＝10＋10t MP/秒
总支付 P＝10＋实际额外注入
伤害 D＝10＋floor(max(0,P−10)/10)
```

额外不足10MP部分仍消耗，但不形成增伤。注魔只提高伤害，不改变恒速3格/tick、中级6秒时限或穿透；理论飞行最远360格。满魔100约68tick/3.4秒耗尽，总付100MP、伤害19。单击按经过tick扣费，不保证总付恰好10MP。

## 7. 续期、地形与即时生成边界

- 水盾与地热原地才可续期；燃烧领域、魔力障壁跟随角色；物理屏障原地续期。松V或中断维护后重放按新实例处理，同人同术领域仅一个。
- 水瀑、火焰放射采用每tick分摊整点预付的持续扣费；停止后0.5秒冷却。源头永久不代表停止后仍无限刷新湿身。
- 土落弹从选点上方6格持续下坠，生物命中不停止，每目标8伤害一次；碰方块或流体停止，空间足够才造完整永久石块；虚空消失。
- 即时查询五术保留12格选点距离：冰柱/冰枪选首个生物或方块；水瀑定期选点放水；风缚选生物；土枪仅生物与自身脚下分支。土落弹另按12格选点后生成下坠巨岩。未命中不把效果延迟成飞行弹体。
- 常规改地形遵守权限、边界与出生点保护，仅在已加载可处理位置操作；临时冰按记录清理且无正常掉落，滴水石按记录状态清理、其他原版交互保留。原版TNT采用其自身破坏规则。
- 火柱只在初次命中位置放地形火，不沿目标移动路径放火；自然蔓延/熄灭仍属原版规则。

## 8. 咏唱与教材学习

施法时长、后冷却及开放范围统一见第2节。

- 未完成咏唱时松V、开GUI、使用原版物品、切换法术、死亡或跨维度均取消，不扣MP、不进后冷却；成功释放才付费。持续法术停止、岩炮弹发射后开始后冷却。
- 咏唱条宽一个物品格，在血量上方原高度水平居中，显示白色剩余秒数；后冷却显示在右上当前魔法HUD。人物咏唱姿态持续至准备结束，原版物品动作优先。咏唱期间周围出现原版附魔文字粒子。
- 分类教材左页显示简介、代码数值与非空先修条件，右页点击学习生成随机银河字母谱。只显示银河字形，不显示对应英文；用A–Z依次试键，按错不失败、不清空，无时限，全部按顺序点亮即学会并提示。
- 字母数按第2节。退出书页、死亡或换书取消学习；已学知识保留。
- 塞妮丝的魔法书、《初级攻击魔法入门》暂可直接学习全部39术，跳过字母谱和先修条件。
