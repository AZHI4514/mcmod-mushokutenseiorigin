# 项目意图与范围

我要做的是Minecraft中的《无职转生》魔法体验：让玩家看得出每种魔法是什么、能理解如何使用，并且视觉尽量接近原作。像素3D是表达方式，不用统一光环代替不同魔法的形态。原作图片/动画优先，GitHub特效项目辅助。

玩家体验目标归intent；准确数值与规则归spec；类名、技术方案、资源路径归impl。原作资料是来源，不自动成为游戏规则。

## 已确认范围与取舍

- 全量审阅稿去重后为116个独立入口：已有39、新设计77，另有1个连续组合。
- 本次确认纳入63个新增独立入口，另加“冰枪暴风雪”连续组合。当前代码注册102项（原39术＋本批63术），另有一个不增加术数的顺序组合；代码接入与游戏验收分别记录。
- 原作设定依据项目《魔术设定》。原文带☆者仍标为补全，不将补全术名、游戏范围和自拟等级称为官方原作设定。本轮未新增可核验官方分级来源，原文未标级的特殊术保持“未标级”，不能猜成上/圣/王/帝/神级。
- 未标级特殊术不改游戏数值：官方等级元数据与游戏计时模板分离。原稿计时r仅作为实现参数保留，所用咏唱、后冷却、标准附效仍为原数值；不得用它给玩家发放官方术阶称号。
- 原有39术的伤害、费用、碰撞、穿透、强风反冲/缓降、全身燃烧领域、咏唱文字与已认可的动画全部保留。
- 暂缓14个新增入口：上级治愈、圣级治愈、再生治愈、奇迹治愈、复活；圣/王/帝/神四档特化解毒；龙门、异世界召唤、转生法、过去转移、佩尔吉乌斯使魔。本批不注册这些技能、生成空技能页或创建其专属资源。
- 暂缓系统：MP自动成长，伤势/器官/断肢/疾病，玩家复活/灵魂锚/转生容器/死亡物资托管，时间回溯，龙门弹体转送，使魔12人组与异世界NPC。魔兽召唤、一般精灵召唤、灯灵仍在范围；它们不是本次排除的佩尔吉乌斯使魔与异世界NPC。
- 解毒III只清现有中毒/反胃/饥饿/虚弱，不引入疾病。为免依赖暂缓治疗术，特殊术学习前置仅作两项范围适配：占命依赖魔力障壁，龙圣斗气依赖城塞结界；两术全部游戏数值保持不变。
- 不重复注册熔岩/溶岩、核爆炸、同术异名；冰枪暴风雪只是原有冰枪与新吹雪的顺序组合。

## 设计权与修改规则

用户决定玩法目标与重要取舍。AI可以提出设计，但未确认的设计标“提案”，不能因代码现状反向写成已确认规则。现有数值不得因整理文档而改变。若新决定冲突，保留旧证据并登记决策，而非并排保留两个有效版本。
