## D-003：施法定义构造后的有效值

SpellDefinition构造器会用CastingProfile覆盖cooldownTicks。冻结实际构造值，不能将旧构造参数当当前冷却，特殊术explicitProfile必须保留。运行时有效快照与源码散落常量哈希共同构成基线。

## D-004：已澄清——基础弹体不设时间/距离上限

上轮将WaterBallEntity.age/distance未递增列为潜在寿命缺失，是未充分核对逐术正式规格造成的误判。本轮对照《魔法-游戏设定》第3节及水弹、火球弹等逐术表：明确不设弹道距离及时间上限，未加载区块挂起。因此不得添加旧lifetimeTicks=100超时；MagicAge/MagicDistance兼容字段继续保留，未改父类或实体生命周期。编译不能替代原版碰撞与存档GameTest，后者仍NOT_RUN。

## D-005：水炮碰块群伤与直击目标集合

intent/spec：直击每目标每发一次；碰块3×3×3群伤，原版无敌帧有效。observed：IntermediateProjectile直击记录MagicVictims，但IntermediateSpells.blockImpact群伤不查询该集合，可能再次对先前直击目标尝试伤害。决定：本次架构迁移保留原流程，不扩大/缩小伤害，不用重构名义统一去重。真实原版伤害验收NOT_RUN；后续逐术/GameTest需要区分直击一次与碰块独立群伤语义。

## D-006：风裂首击AOE表述与穿透后再次群伤

intent/spec：第32术写首个命中生物中心3格群伤，同时写恒速穿透每经过生物结算原范围效果。observed：PhaseTwoEntity对每个尚未claim的直击目标展开3格候选，不限全发首次；直击和AOE共用ImpactHistory，先前被AOE命中的目标不会再次直击触发。多个不重叠新直击可再次展开群伤，无逐目标视线。

本轮决定：仅保留现有流程抽取结构，不变更玩法、不反改正式设定。首击限定与通用穿透补充之间仍需明确，未获明确决定前不写“与设定完全一致”或整术DONE。差异不阻止等价准备/释放/纯协调重构与离线测试。真实原版伤害/多次爆发效果NOT_RUN。独立于D-005的水炮碰块群伤身份问题。
