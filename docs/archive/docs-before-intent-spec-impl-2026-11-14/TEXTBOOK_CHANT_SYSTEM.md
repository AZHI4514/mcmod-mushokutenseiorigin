## 教材

分类教材按当前已注册法术的实际类别与等级生成课程，覆盖已实现的初—神级法术；冰归水，解毒独立于治愈，混合、神击、召唤、特殊按实际目录分类。不得把旧14/16本的数量作为当前固定白名单。塞妮丝书从`SpellDefinition.ALL`生成全部102项，入门书保留原39项；组合不另建学习ID，暂缓未注册术不收录。法术简介参考[原作设定](魔术设定.md)，游戏数值以正式游戏规格及定义核对，分类教材显示非空前置。

学习由服务端校验实际持书、课程和前置；分类教材生成随机A–Z银河字母谱，仅显示原版ascii_sga字形，不显示对应英文字母。玩家用字母键逐个尝试，按错不失败、不推进、不清空已点亮进度；无倒计时、漏拍或精度门槛，全部按顺序点亮即学会。初级4–6枚、中级6–8枚，上级8–10枚、圣级10–12枚；王级3段各8–10枚、帝级4段各10–12枚、神级7段各10–12枚。王/帝/神级保存已完成段，退出时当前未完成段重来。退出界面、死亡和换书取消会话；塞妮丝与入门书仍按各自目录直接学习。

## 表现与验证

材质参考棕色皮革压纹封面、分类色符号、羊皮纸双页，32×32透明物品图标。素材生成源保存至D:/LibreSprite-art-source，运行时资源使用项目相对资源ID。咏唱条宽20 GUI像素（一个物品格），左上角位置不变，叠加白色剩余秒数，位于血量上方；后冷却覆盖右上角已选魔法HUD。人物保持物理右臂前伸、左臂扶近右前臂的姿势中心，并有连续微动；银河每4tick一字，从左眼斜上漂浮渐隐。粒子和动作参数见[视觉规范](PIXELFX_ANIMATION.md)，原版物品动作优先。

需验证分类白名单、旧知识兼容、挑战窗口与错误输入、取消不扣费、后冷却、持续/注魔阶段转换、资源完整性，并运行Java25离线build。构建不能代替游戏内双视角、GUI缩放和联机验收。不启动游戏，不进行Git add/commit/push。

学习按键仅通过按键事件提交并屏蔽系统长按重复，服务端确认当前完成索引；咏唱进度条宽20GUI像素，在原高度水平居中，保留白色剩余秒数。所有教材保留原版书透明外形，参考素材使用皮革棕/塞妮丝浅棕封面与米色纸页，分类图案逐像素描画，避免斜向压缩混色。
