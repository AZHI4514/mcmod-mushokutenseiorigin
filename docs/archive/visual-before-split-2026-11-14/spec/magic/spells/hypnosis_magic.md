# 催眠魔术 · `hypnosis_magic`

规则归属：本术效果与数值。设计目标见[魔法意图](../../../intent/MAGIC.md)；共同规则见[通用魔法规则](../RULES.md)。本卡不拥有教材、学习前置、按键或代码路径。

## 玩法规则

| 字段 | 规则 |
|---|---|
| 等级/计时模板 | 官方未标级 |
| MP | 30 |
| 游戏效果与准确范围 | 16格内单个非首领，普通生物睡眠8秒、玩家2秒；受任意伤害立刻醒；同目标清醒后10秒免再次催眠 |
| 形态/时长/地形 | 不跳过世界夜晚、不当作原版床睡眠，不因此回满MP；被催眠玩家仍可开菜单和聊天，不强制退出游戏 |

- 正常：满足资格与本术目标条件，按上表支付MP并产生规定效果，不追加未设计的伤害或地形。
- 边界：逐项验证上表距离/体积/时间边界；不适用字段明确N/A，不凭名称推断范围。
- 失败与中断：遵守施法合同；无效果拒绝与不可逆部分异常分别处理，不能统一假定退款。
- 兼容：保留本ID、旧存档与资源标识；具体测试位置由实现索引导航。
