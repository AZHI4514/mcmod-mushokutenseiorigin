# 中级魔法补全：用户确认设计

记录日期：2026-11-07。目标：Minecraft 26.1 / Fabric / Java 25。

状态：用户已于归档后授权实现下表18术，现进入代码与离线验证阶段；游戏内视觉、碰撞及联机尚待实测。本文的新数值与效果优先于此前建议，不代表已经实现或验收。已实现的六个中级魔法仍见 `INTERMEDIATE_MAGIC_PHASE1.md`。

## 范围与共同决定

- 本批一次性完成下表18个魔法，不再按此前建议拆成三批。
- 临时冰、土柱、冰墙只填空气，不覆盖原有方块，无掉落；到期只清理本次生成物，复用现有临时冰的到期持久化和替换保护机制。
- 持续施法每tick计费，松开V、打开GUI、使用原版物品或魔力不足立即停止；不套用普通连发。4/秒与6/秒需要保留小数计费余量，不能每tick直接截断成0。
- 风缚第一版限制水平移动，不完全定身，不禁止攻击；首领免疫可配置。
- 两本现有教材继续扩充，内容相同，不新增书物品。
- 归档阶段只写文档；后续已授权落实18术代码。仍不执行git add、commit或push，不自动启动Minecraft，不修改外部原始设定文件的高亮。

## 继承规则与明确变化

- 伤害/恢复单位为原版生命值，2点为一颗心；既有护甲、受伤机制、PVP与抗火规则继续有效，除明确特殊行为外不绕过。
- 等级状态时长：初级5秒，每增加一级加5秒；本批中级为10秒。水瀑100%接触湿身采用此规则，不继承水蒸单独调整为100秒的特例。
- 冰系80%冻结、水系60%湿身、火系80%点燃沿用已有规则；水瀑的接触湿身100%为明确覆盖。水瀑不需要造成伤害才触发其接触效果。
- 物理障壁“与水盾一致”继承连续按住且不移动时付费续期、每次增加基础持续时间并恢复承伤值的规则；松键/移动打断旧实例的续期资格，切换魔法不立即清除既有效果。
- 爆炸伤害体积和破坏体积均为边长5的立方体，各为5×5×5；不是半径5，也不沿用水炮/大火球的1×1×1或2×2×2破坏范围。
- 爆炸破坏条件改为至少一种原版石制工具能够挖掘且掉落，沿用工具正确性与实际掉落检查思路；不以爆炸抗性代替采集等级。具体工具种类在实现时以当前版本原版物品注册为准。
- 强风为完整三维准星方向的反方向位移6格，不沿移动输入方向、不限定水平，并新增摔落免疫。
- 土枪脚下分支生成永久泥土；土落弹落地生成永久石头。这两项是临时造物规则的明确例外，不设置自动到期清理。
- 疾病、自定义幽灵/魔物等未实现系统继续预留接口，不把接口存在当成依赖已实现。

## 实现前仍需明确的边界（不擅自补为已确认规则）

1. 强风的摔落免疫：建议从冲刺开始覆盖到本次首次落地，落地后立即解除；死亡、退出、跨维度清理，不能变成永久免摔。
2. 永久泥土/石头生成：建议仍只填空气并检查修改权限，不覆盖原有方块和流体；普通永久方块是否允许正常挖取掉落，需要确认。该分支与“临时造物无掉落”不同，不能混为一谈。
3. 土枪顶起：遇天花板、非完整空间时是部分生成还是整次失败；建议顶起前验证目标可用空间，禁止强行穿墙或挤入天花板。脚下“非空气/流体”按非空气且非流体理解，若要允许对水面施法需另行确认。
4. 土落弹：接触生物与接触方块的伤害是否整发只结算一次、生成石头是否避开实体占用空间；建议只伤一次，不因落地再次伤害，且不把永久石头直接填进生物体内。
5. 持续施法：水幕落点是否随准星更新，火焰是否随准星转向，开始与中途小数魔力不足如何结算。建议服务端固定精度累计计费，不能用反复点按逃费；这些细节仍需形成实现规范。
6. 冰霜击仍保留原版受伤无敌时间，因此5枚各2伤害不保证同一目标合计10伤害；本设计未授权绕过无敌帧。
7. 冰柱、土枪、水流、冰枪等对施术者本人的攻击判定，火柱的选点距离、首次伤害时点，风缚首领标签及减速参数，物理障壁的近战阻挡方向/伤害分类与实体通行方式，均需在编码前明确。建议攻击排除施术者，脚下土枪只顶起不伤本人。
8. 爆炸是否主动点燃地形尚未指定；“火系80%点燃实体”不等于放置原版火焰方块。

## 本轮实现采用的边界与入口

本节记录实现选择；神击不在本轮18术内，仍待初级神击参数确认，不能宣称全部中级已补齐。

- `SpellDefinition` 与 `MagicBooks` 共39术/39课，旧ID不变，轮盘仍10槽。18术复用既有服务端校验、教材自动分页与属性状态；未新增物品、依赖或法杖。
- `PhaseTwoSpells` 处理预检、实体选取、精确地形与一次性执行；`PhaseTwoEntity` 使用同步法术ID与朝向，处理连续体积碰撞、火柱接触与水幕。客户端 `PhaseTwoRenderer` 使用原版图集，并提供月牙冰刃轮廓。
- `PhaseTwoRuntime` 处理持续施法、五连发队列、物理障壁与首次落地免摔；`PhaseTwoRules` 保存独立可验证的定点计费、锥形和限速规则。不存在客户端上报伤害或消耗量的入口。
- 水瀑固定本次开始的落点，停止即移除；火焰放射跟随有效施法心跳的准星。心跳丢失超过6服务端tick停术；正常GUI/松键会立即发停止包。均按每tick的4/20或6/20魔力计费，开始预付首个tick；不足1点的预付余额以二十分之一为单位持久化跨停术、切换与重进保留，避免点按逃费，停止才设1秒冷却。水瀑接触湿身10秒，不继承水蒸100秒特例。
- 冰霜击五发方向取释放瞬间准星，每隔2tick发出下一枚；已付款的队列在松键/切换时继续，死亡、退出或跨维度取消剩余发射，不退款。原版无敌帧不绕过。
- 冰柱/土枪与冰墙朝水平四向贴合方块网格；建造前检查全部目标位置权限、空气和顶起通路，空间不足整次失败且不扣费。临时造物使用独立方块和方块实体到期时间，200tick后清理，无掉落；脚下永久泥土柱除外。攻击排除本人，脚下土枪分支不伤任何生物。
- 永久泥土和石头是原版方块，可正常采集掉落；仅填空气，不覆盖已有地形/流体。巨岩首次接触生物时结算一次范围伤害并继续下降；接地后若此前未伤害再结算一次，否则不重复伤害；永久石头跳过生物占用的位置。受保护区域不能造地形。
- 爆炸为命中点中心5×5×5伤害体积，精确5×5×5方块列表按命中点所在方块中心对齐。只破坏石工具实际可采且有掉落的方块；生物需可见，不主动放置火焰，成功命中后保留火系着火判定。
- 火柱选地距离12格，首次接触立即尝试伤害，同目标20tick节流；冰枪只结算一次，视觉12tick后消失。火柱不放火方块。
- 强风按完整准星反向对玩家包围盒逐0.1格检查，最多6格，遇方块/实体碰撞、世界边界或未加载区块停止；到达已验证终点后同步位置。免摔只到首次落地；死亡、旁观、退出或跨维度清除。不提供持续飞行。
- 风缚施加3秒强减速，并在两端的实际移动入口把每次水平位移限制到0.025格，垂直移动/重力、视角和攻击不取消。可用数据包覆盖 `data/mushokutenseiorigin/tags/entity_type/wind_bind_immune.json`；默认末影龙、凋灵、监守者免疫。
- 物理障壁朝最近的水平四向摆放，实际矩形包围盒与渲染一致，避免斜放后的保守AABB挡住额外空间。本人可通过，其他实体阻挡；迎面物理弹体与穿过面板的实体攻击消耗承伤值；模组魔法穿过，不拦环境伤害。普通弹体无直接伤害时不扣盾值，但拦截；三叉戟反弹不销毁。连续静止付费续期增加160tick、回满16承伤，移动/松键/原版用物/切换终止旧实例续期资格，已有障壁不会立即消失。
- 解毒II只处理原版中毒、反胃、饥饿；后续疾病仍需单独接入。中级治愈只恢复本人8点并截断到生命上限，满血不消耗。

## 2026-11-07 测试反馈修订（优先于上文旧行为）

- `ice_pillar`：射出最远12格光线，首次命中生物或方块时升起1×3×1临时冰柱，持续10秒；弹起目标并造成4点伤害一次。空间不足施法失败。
- `waterfall`：按住V，每秒消耗4魔力。光线命中12格内生物或方块，在命中位置旁的空格生成一格原版水源，可自然流动蔓延、减速和灭火，接触者必定湿身10秒。松键或打断后移除源头，流水按原版退去，冷却1秒。
- `ice_lance`：射出最远12格光线，首次命中生物或方块时，向上刺出3格冰枪，范围1×3×1，造成8点伤害；视觉随后消散。
- `icicle_break`：发射一枚冰弹，伤害2，射程18格；按住V可在冷却后持续射击，不再一次发射五枚。
- `icicle_edge`：宽3、高1月牙冰刃，沿准星直飞18格，穿透生物，每目标6点伤害一次；仅在刃体截面被完全挡住时消失，可穿过部分遮挡的空隙。
- `flood_flush`：沿准星完整方向发射宽3格水浪，推进8格，可在空中飞行；每目标2点伤害并击退1.2，不留下水源。
- `ice_fortress`：在玩家同一高度、准星水平方向前方2格生成宽5、高3、厚1临时冰墙，持续10秒，可在空中生成。只填空气，不覆盖方块。
- `explosion`：射出最远12格光线，首次击中生物或方块后触发爆炸；5×5×5范围造成10点火伤，5×5×5地形爆炸仅破坏石制工具可采集且有掉落的方块。
