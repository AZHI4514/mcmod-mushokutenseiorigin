│  └─ 初级 → 中级 → 上级 → 圣级 → 王级 → 帝级 → 神级
│     （圣级以上威力随魔力量增加；神级可覆盖大陆规模）
│     ├─ 称号：习得某系某级即称「○属性○级魔术师」（如水圣级魔术师），只代表术的难度，不代表综合战力
│     ├─ 秘藏：圣级以上的咏唱与术式由王侯/教团秘藏；王级以上多为「圣级混合术的改编」
│     ├─ 越级：低级术注入大量魔力可打出圣级～帝级威力（鲁迪式无咏唱的核心用法）
