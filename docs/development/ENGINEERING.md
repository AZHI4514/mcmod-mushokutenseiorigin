# 工程约束

Minecraft 26.1 / Fabric / Java 25，沿用现有依赖不擅自升级。Java用UTF-8、LF、Tab和同行大括号。保留工作区既有改动，禁止reset覆盖；运行资源不得依赖本机绝对路径。

服务端负责知识、持书、MP、冷却、目标、权限与提交；客户端只表现。状态通过附件/Codec持久化，网络动作核验长度/序列与会话，不相信客户端“成功”。旧注册ID、资源ID、存档键、网络字段顺序改变需迁移方案。

新增术必须接通定义、纯规则、用例/适配、装配、资源和表现；教材是独立系统的ID关联，不把课程逻辑写进魔法类。失败spawn、无效果拒绝和已发生部分世界效果分开处理，不能把所有异常当可退款。

核心生产依赖只允许JDK；src/main不导入客户端；src/client不得依赖服务端世界适配。新机制先核对已有端口，避免为每术建空工厂或通用解释器。

构建：`.\gradlew.bat build --offline`。文档检查：`python tools/verify_docs.py`。纯规则/模块/架构/资源/存档fixture检查不等同Fabric加载、真实世界、视觉、联机或性能验收。实际执行命令和结果写日志及STATUS，不写本文件。

法术开发走[标准流程](WORKFLOW.md)，物品走[物品规范](ITEMS.md)，架构见[impl](../impl/ARCHITECTURE.md)。
