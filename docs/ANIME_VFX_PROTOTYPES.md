# 原作参考特效：五个样板

本批只替换 water_ball / fireball / ice_smash / rock_bullet / water_shield。其余34术保留；不以批量改色代替独立设计。

WebP统一为40ms/帧，但剪辑包含人物镜头与慢镜。参考时序用于阶段比例，未把整个片段长度强加给游戏技能。

## 阶段

- 凝聚 FORM：既有准备进度驱动总体生长；水滴向液体聚合，火舌上升，冰尖错峰结晶。
- 飞行 FLIGHT：水体连续轻微变形与后置水滴；火焰沿速度反方向拖尾，岩石刚性缓转，冰簇保持刚性。
- 命中 IMPACT：沿原速度建立局部XY散开平面。水核4tick内压扁消失并散出水滴；火核5tick内扩张熄灭，14tick内余焰散尽；冰/石主体3tick内消失，碎片20tick内散开、下落、渐隐。
- 水盾：6tick展开、网格波动、错落水流与边缘喷滴；沿用服务端80tick寿命，当前协议没有命中位置事件，因此不伪造“命中处涟漪”。

## 素材与运行时

通过本机Blockbench MCP创建free mesh、材质UV、编辑器动作并导出，不手写bbmodel冒充建模。编辑器动作是运动研究；实际客户端ReferenceSpellModels进行逐顶点流动及阶段动画，二者不是同一套播放器。

游戏几何：models/effect/reference/<id>.json；纹理：textures/effect/reference/<id>.png，128×768，24张128×32帧，由客户端手动采样。PNG元数据只配置最近邻与clamp，不能再添加原版animation元数据重复切帧。

五个可编辑源：model-source/magic_effects/<id>.bbmodel。每个模型使用四个32px材质岛，水/火保留透明度，岩石/冰使用连续大色面，不继续采样原版方块噪点。未修改39术旧纹理目录以免覆盖其余34术；这五术渲染入口明确改为reference目录。

视觉弹体尺度：水.42、火.45、冰.6、石.4格基础尺度，叠加模型自身边界；碰撞、伤害、耗魔、寿命、状态和网络协议均未调整。水盾仍是3×2，侧面视觉曲率不扩大碰撞。

命中效果沿用最多24实例/48格剔除，五个样板每实例一次自定义几何提交；没有增加无限粒子实体。吟唱保留左眼斜上漂浮、逐tick银河字符与渐隐；手边原有增量不回退。

## 验收边界

离线检查：真实导出网格/UV/透明度/纹理路径，阶段几何和寿命，Gradle构建与verifyMagic。Blockbench截图只能检查形体/UV，不能证明游戏透明混合、遮挡和最终观感。

需要游戏内检查：明暗背景下水体透明叠加、第一人称遮手、正/侧/后视轮廓、上下瞄准尾迹、命中墙/地面、水盾与箭拦截对应、多人同时施法帧时间。未经用户要求不自动启动Minecraft；未实测项目不标记通过。
